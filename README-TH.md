# StoryCraft Studio 1.7.0 — ให้เพลงนำทางเรื่อง

เว็บหลัก: https://thanawid.github.io/storycraft-studio/

## สิ่งที่พัฒนาแล้ว

- เริ่มจากเพลง/เนื้อเพลง/ไอเดีย ให้ Gemini เสนอแนวเรื่องภาษาไทย 3 แบบ มีเปิดเรื่อง จุดเปลี่ยน และตอนจบ เลือกแนวที่ต้องการก่อนสร้างช็อต หรือเขียนเรื่องเองได้
- AI ส่งเสียงสำหรับวิเคราะห์ผ่าน Worker ใช้คีย์ที่หลังบ้าน ไม่ต้องกรอกคีย์บนเว็บ ระบบไม่ส่งคำขอซ้ำเมื่อโควตาเต็ม
- จัดสถานที่แบบใช้ซ้ำ: ชื่อ รายละเอียดพื้นที่ เวลาและแสง ล็อกข้อมูล แล้วผูกกับช็อต AI ใช้เฉพาะ ID สถานที่ที่มีอยู่
- แผงผลิต MV 9 ขั้นนับไฟล์จริง ช็อตที่ตรวจผ่าน และการส่งออกตามข้อมูลปัจจุบัน เลือกเป้าหมายสตอรีบอร์ด/ภาพ/วิดีโอเพื่อวางแผนได้
- ส่งออกคู่มือช็อตไปทำใน Flow รวม Prompt ต้นแบบที่ต้องแนบและ SHA-256 แล้วนำภาพ/คลิปกลับมาตรวจในช็อตเดิม
- มีคำสั่งคิดเรื่องให้ Flow และนำเข้า JSON แนวเรื่องตามโครงสร้างของเรา ไม่รองรับไฟล์โปรเจกต์ Jarvis
- หน้าแรกเน้น MV รักษา Login สีส้ม เทา เขียวพาสเทล เอฟเฟกต์ที่ปิดได้ และฟังก์ชันหนัง/ละคร/นิทานเดิม
- ความยาวต่อช็อตเพิ่มตัวเลือก 5 วินาทีให้ตรง Kling โดยค่าเริ่มต้นไม่หายจากรายการ

## อัปเดตเว็บและ Worker ตามนี้

1. สำรอง JSON โปรเจกต์บนเว็บเดิมก่อน ข้อมูลอยู่ในเบราว์เซอร์เครื่องเดิม
2. Cloudflare → Workers & Pages → storycraft-api → Edit code: ใช้ **backend/kling-worker.js ที่ราก ZIP** ทับโค้ดและ Deploy ไฟล์นี้ bundle เป็นไฟล์เดียวแล้ว
3. เก็บ Secrets เดิม: STUDIO_PASSWORD, GEMINI_API_KEY, KLING_API_KEY (ถ้าใช้ Kling), GEMINI_MODEL และ ALLOWED_ORIGIN=https://thanawid.github.io ไม่ต้องใส่คีย์ใหม่
4. อัปโหลด index.html, assets, storycraft-icon.svg และ .nojekyll จากราก ZIP ไปที่ราก repository thanawid/storycraft-studio รอ Pages แล้วรีเฟรชให้เห็น v1.7.0
5. เปิดโปรเจกต์ → เรื่องและเพลง → อัปโหลดเพลง → ยืนยันส่งข้อมูล → คิดแนวเรื่อง 3 แบบ → เลือกเรื่อง → ล็อกตัวละคร/สถานที่/สไตล์ → สร้างสตอรีบอร์ด → ผลิต MV → นำไฟล์กลับมาตรวจ → ส่งออก

**ต้องอัปเดต Worker ด้วย** รุ่นนี้มี /api/concepts เพิ่ม หากอัปโหลดเฉพาะเว็บ ปุ่มคิดแนวเรื่องจะยังไม่ทำงาน
ห้ามวาง source/backend/kling-worker.js ตรง Dashboard เพราะเป็น source ที่มี import ใช้ไฟล์ backend ที่ราก ZIP

## ขอบเขตที่ต้องรู้

เป้าหมายการผลิตเป็นแผนงาน ไม่เริ่มสร้างแบบจ่ายเครดิตหรือสร้างทุกช็อตอัตโนมัติ ภาพและคลิปใน Flow ยังสร้างและนำกลับเอง เว็บนี้ยังไม่ใช้เครดิต Flow ของบัญชีผ่าน API โดยตรง
Kling ในหน้าช็อตสร้างทีละคลิป 5/10 วินาที จากภาพเริ่มที่ตรวจผ่าน มีเงื่อนไขตัวละครหนึ่งคนและภาพต้นแบบเดิม ไม่รองรับภาพนิ่งอัตโนมัติหรือหลายตัวละครในคำขอเดียว
วิดีโอส่งออกจริงจากภาพ/คลิปที่ตรวจแล้วและเพลงต้นฉบับ ใช้เวลาเท่าความยาวเรื่อง ผลเป็น WebM หรือ MP4 ตามเบราว์เซอร์ ภาพนิ่งจะเป็นสไลด์ คลิปสั้นค้างเฟรมสุดท้าย
แผงระบุส่งออกแล้วเฉพาะหลัง render สำเร็จและเริ่มดาวน์โหลด ไม่ได้ตรวจว่าไฟล์ดาวน์โหลดถูกบันทึกในเครื่องเรียบร้อยหรือเก็บวิดีโอเต็มในโปรเจกต์
สถานที่รุ่นนี้เป็นข้อมูลข้อความ ยังไม่มีภาพอ้างอิงสถานที่ คิวสร้างเป็นชุด พัก/ทำต่ออัตโนมัติ เสียงพูด แคปชัน หรือปกอัตโนมัติ
การล็อกตัวตนเป็นกฎคำสั่งและการตรวจด้วยคน ไม่รับประกันผู้ให้บริการคงหน้าทุกเฟรม ห้าม AI ซ่อมหน้า สลับหน้า สร้างหน้าใหม่ หรือใช้ภาพสร้างแล้วแทนต้นแบบ
Gemini 429/503 ยังขึ้นกับโควตาและบริการ การอัปเดตเว็บไม่เพิ่มเครดิต

## Source และการตรวจ

source เป็น React/Vite: npm install → npm run typecheck → npm test → npm run build → npm run build:worker
เว็บออกที่ source/dist Worker ออกที่ source/worker-dist/kling-worker.js
TypeScript, build เว็บ/Worker และทดสอบจำลอง 58 ข้อผ่าน ไม่ได้เรียก AI แบบใช้เงินจริงหรือทดสอบสร้าง MV ครบในเบราว์เซอร์
ยังไม่ได้เผยแพร่แทนคุณ: GitHub connector ตอบ 403 เมื่อเขียน repository ให้ใช้ชุดนี้อัปโหลดเอง
ห้ามอัปโหลด node_modules, .env, Secrets หรือคีย์ใด ๆ ไป GitHub
ดู HANDOFF.md สำหรับการส่งต่องานและข้อจำกัดที่ต้องรักษา
