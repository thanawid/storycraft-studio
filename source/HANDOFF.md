## สิ่งที่ทำแล้ว

### เว็บ 1.4.0–1.4.1
เพิ่มตัวเชื่อม Kling 2.6 ผ่าน Worker ป้องกันด้วยรหัสเจ้าของ รองรับ image-to-video ทีละช็อต 5/10 วินาที 720p ปิดเสียง
เลข external task ID และภาพเริ่มบันทึกก่อนส่งคำขอ ไม่มีการส่ง POST สร้างซ้ำอัตโนมัติเมื่อเน็ตหลุด
ผลคลิปยังต้องดาวน์โหลดและแนบกลับในช็อตเอง
Kling โหมดตัวละครของเว็บนี้รองรับหนึ่งคน โดยใช้ภาพต้นแบบเดิมเป็น first frame ยังไม่ส่งหลายภาพอ้างอิงแยก

### เว็บ 1.5.0 / Worker 1.5.0
ย้าย Gemini key ไป Cloudflare Secrets เช่นเดียวกับ Kling ผู้ใช้ไม่ต้องกรอก API key ในเว็บ
จำเซสชันบนเครื่องส่วนตัวได้ 7 วัน หรือเลือกเฉพาะแท็บ 1 ชั่วโมง ไม่เก็บรหัสเจ้าของหรือคีย์ AI ใน localStorage
เพิ่มบริการคิดเรื่อง /api/story ผ่าน Worker ส่งเสียงและภาพอ้างอิงต้นฉบับพร้อมตรวจ SHA-256
แยกความผิดพลาดเซสชันเจ้าของออกจาก key/โควตาผู้ให้บริการ ตรวจสิทธิ์โมเดลได้โดยไม่สร้างเรื่อง
โควตา Gemini 429/503 ยังไม่ได้แก้ด้วยการย้ายคีย์ และไม่มีเวลาเปิดบริการที่รับประกันได้

### เว็บ 1.6.0 (ชุดล่าสุดที่จัดทำ)
เพิ่มหน้า Login ก่อนเข้าสตูดิโอ กราฟิก CSS ส้มอุ่น/เขียวพาสเทล/เทาอ่อน ตัวหนังสือเข้มขึ้น
เครื่องที่จำไว้ต้องตรวจเซสชันกับ Worker ก่อน แล้วหน้า Login แสดงปุ่มเข้าสู่สตูดิโอโดยไม่ถามรหัสซ้ำ
ปุ่มแสดง/ซ่อนรหัสผ่าน ออกจากระบบ และบันทึกโปรเจกต์ก่อนออกจากระบบ
บัญชี THANAWID ที่แสดงเป็นชื่อเจ้าของคงที่ ไม่มีระบบสมัครหลายบัญชีหรือการตรวจ username แยก
ใช้ Worker 1.5.0 เดิมได้ ตรวจ TypeScript, build และทดสอบจำลองผ่าน 52 ข้อ
ยังไม่ได้ตรวจหน้าจอจริงของ 1.6.0 ในเบราว์เซอร์ ไม่ได้เรียกสร้าง AI ด้วยคีย์จริงหรือใช้เครดิตระหว่างพัฒนา
ยังไม่ยืนยันว่าผู้ใช้อัปโหลด 1.6.0 แล้ว ภาพล่าสุดที่ยืนยันรุ่นเว็บชัดเจนก่อนหน้านั้นเป็น 1.5.0 ให้ตรวจ live version ก่อนอ้างว่าเผยแพร่แล้ว

## อุปสรรคที่พบจริง

- GitHub อ่าน metadata ได้ แต่การเขียน create_blob ถูกปฏิเสธ 403 Resource not accessible by integration แม้ metadata รายงาน push:true อย่าอ้างว่า push สำเร็จ ต้องแก้สิทธิ์การเชื่อมต่อหรือให้ชุด ZIP อัปโหลด
- ผู้ใช้ยืนยันเข้าสู่ระบบหลังบ้าน Kling ผ่านแล้วจากหน้าจอ แต่ยังไม่มีหลักฐานว่าคลิปจากเว็บเราสร้างสำเร็จจริง
- Gemini เคยตอบทั้งโควตาและ 503 ภาพล่าสุดก่อนหน้า Login แสดง 503 ไม่ควรตีความเป็นคีย์ผิดเสมอ
- การตรวจคีย์/โมเดลผ่านไม่ยืนยันเครดิต โควตา หรือผล generation
- ไม่มีตัวควบคุมเบราว์เซอร์สำหรับ visual QA ที่ใช้ไปแล้ว จึงไม่เคยยืนยันการทดสอบหน้าจอจริง อย่าอ้างว่าทดสอบมือถือจริงแล้วจาก build อย่างเดียว

## สิ่งที่ผู้ใช้แสดงเกี่ยวกับ Flow

ตัวอย่างเป็น Remix of Jarvis Series Studio V5 ภายใน Flow มีเมนูคิดพล็อต ตัวละคร สตอรีบอร์ด สร้างภาพ สร้างวิดีโอ และพรีวิว
สองภาพล่าสุดระบุว่า “รอผลจากบริการข้อความของ Flow” และแสดงชื่อเรื่อง “เลขเด็ดแม่ตานี” เรื่องย่อ/บทสรุป และตัวละคร กานต์/นางตานี
ภาพยืนยันบริการคิดเรื่องและตัวละคร แต่ยังไม่ยืนยันว่าทุกขั้นตอนผลิตคลิป/หนังเสร็จจริง
ผู้ใช้ซื้อ/เข้าถึงเครื่องมือ Jarvis แล้ว ใช้เป็นตัวอย่างความสามารถ ไม่คัดลอกชื่อแบรนด์หรือ source ของผู้อื่นโดยไม่มีสิทธิ์

## ลำดับงานถัดไป

1. ทำข้อกำหนด StoryCraft Flow Edition ให้สร้างเครื่องมือของเราเองใน Flow: คิดชื่อ เรื่องย่อ บทสรุป ตัวละคร และสตอรีบอร์ดก่อนผลิตสื่อ
2. แยกขั้นคิดเรื่องออกจากขั้นใช้เครดิตสร้างภาพ/คลิป พร้อมปุ่มตรวจและยืนยันเป็นรายช็อต ไม่กดสร้างทั้งเรื่องโดยอัตโนมัติ
3. เริ่มชุดทดลองเล็ก ๆ 1–3 ช็อต ตรวจการอ้างอิงตัวละครจริง เครดิตจริง และการบันทึกงานก่อนเพิ่มงานทั้งเพลง
4. ตรวจความสามารถจริงของ Flow Tools เรื่องรับไฟล์เสียง, โครงสร้างข้อมูล, ส่งออก/นำเข้า และตัวเชื่อมสื่อ ห้ามคิดว่า MP3 ทั้งเพลงหรือ JSON ของ Jarvis รองรับอยู่แล้ว
5. เสนอรูปแบบแลกข้อมูลระหว่างเว็บกับ Flow หลังรู้ schema จริง: โปรเจกต์ ตัวละคร ภาพต้นแบบ hash ช็อต Prompt และผลลัพธ์
6. ทดสอบการผลิตครบหนึ่งเส้นทางด้วยบัญชีผู้ใช้เมื่อได้รับสิทธิ์ใช้งานที่จำเป็น ไม่อ้างว่าทำคลิปสำเร็จจาก mock tests

## เกณฑ์ความสำเร็จ

ผู้ใช้กรอกแนวเรื่อง/เพลง ได้เรื่องและตัวละครที่แก้ไขได้ ล็อกต้นแบบ ทำสตอรีบอร์ด สร้างสื่อใน Flow ด้วยเครดิตของตน ตรวจแต่ละช็อต และบันทึกกลับมาทำต่อได้
ต้องมีหลักฐานผลสำเร็จจริงและงาน/เครดิตที่ใช้ แสดง error ที่แก้ได้ ไม่ทิ้งผู้ใช้กับปุ่มที่ทำงานจำลอง
ชื่อโครงการ สี ภาพต้นแบบ และเว็บหลักข้างต้นต้องคงต่อเนื่อง บันทึกสิ่งที่เปลี่ยนและข้อจำกัดทุกครั้งก่อนส่งต่องาน

อย่าคัดลอกการลองใหม่ 3 รอบแบบจ่ายเครดิตอัตโนมัติ โดยเฉพาะกรณีไม่ทราบว่างานแรกถูกส่งหรือใช้เครดิตไปแล้ว ต้องกู้สถานะงานเดิมก่อน
ผู้ใช้ยังไม่ได้อนุมัติให้เริ่มสร้างสื่อแบบใช้เครดิตเป็นชุดหรือให้ส่งคำขอซ้ำโดยอัตโนมัติ
