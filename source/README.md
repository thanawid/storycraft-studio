# StoryCraft Studio 1.6.0 — หน้า Login และโทนสีใหม่

เว็บหลัก: https://thanawid.github.io/storycraft-studio/

## เพิ่มในรุ่นนี้

- หน้า Login แยกก่อนเข้าสตูดิโอ พร้อมกราฟิกสตูดิโอ ส้มอุ่น เขียวพาสเทล เทาอ่อน และตัวอักษรเข้มอ่านง่าย
- บัญชีเจ้าของ THANAWID ใช้รหัส STUDIO_PASSWORD เดิม ไม่มีระบบสมัครหลายบัญชีหรือการตรวจ username แยก
- ปุ่มแสดง/ซ่อนรหัสผ่าน จำเครื่อง 7 วัน และปุ่มออกจากระบบ
- เครื่องที่จำไว้ต้องตรวจเซสชันกับหลังบ้านก่อน เมื่อผ่านจะเห็นปุ่มเข้าสู่สตูดิโอโดยไม่ถามรหัสซ้ำ
- หากหลังบ้านตรวจไม่ได้จะไม่ปลดล็อกสตูดิโอเงียบ ๆ และไม่ลบเซสชันที่จำไว้
- ก่อนออกจากระบบจะบันทึกโปรเจกต์ในเครื่อง สีของปุ่มหลักและข้อความถูกปรับให้เด่นขึ้น การ์ดเลือกสไตล์ที่ล็อกแล้วไม่ซีดจาง

## ถ้าใช้ 1.5.0 อยู่แล้ว อัปเดตเฉพาะเว็บ

1. สำรอง JSON โปรเจกต์จากเว็บเดิมก่อน
2. แตก ZIP แล้วอัปโหลด index.html, assets และ storycraft-icon.svg ทับไฟล์ที่ราก repository thanawid/storycraft-studio
3. รอ GitHub Pages เผยแพร่แล้วรีเฟรชให้เห็น v1.6.0
4. จะพบหน้า Login ใช้รหัสเจ้าของเดิม หากจำเครื่องอยู่แล้วกดเข้าสู่สตูดิโอได้เลย

**ไม่ต้องแก้ Cloudflare หรือใส่คีย์ใหม่ หาก Worker เป็นรุ่น 1.5.0 แล้ว**
ไฟล์ backend/kling-worker.js ในชุดยังเป็น Worker 1.5.0 ที่เข้ากับหน้าเว็บนี้
หากยังใช้ Worker 1.4.x ให้ทำขั้นตอนใน backend/SETUP-TH.md ก่อน

## ขอบเขตการเข้าสู่ระบบ

หน้า Login ควบคุมทางเข้าของ UI และตรวจเซสชันกับหลังบ้าน บริการ AI ทุกคำขอยังคงต้องยืนยันสิทธิ์ที่ Worker
GitHub Pages และ source code ยังเป็นสาธารณะ การบันทึกโปรเจกต์ใน IndexedDB ไม่ใช่การเข้ารหัสไฟล์ และผู้เข้าถึงเบราว์เซอร์เครื่องเดียวกันอาจเข้าถึงข้อมูลในเครื่องได้
อย่าเลือกจำเครื่องบนเครื่องสาธารณะหรือใช้ร่วมกับผู้อื่น
รหัสเจ้าของและคีย์ AI ไม่อยู่ใน localStorage, source หรือ ZIP การจำเครื่องเก็บเฉพาะเซสชันที่มีอายุจำกัดและให้สิทธิ์ใช้เครดิต
ออกจากระบบเพื่อลืมเครื่องนี้ หากต้องยกเลิกเซสชันทั้งหมดให้เปลี่ยน STUDIO_PASSWORD ที่ Cloudflare

## AI และภาพต้นแบบ

Gemini ใช้คีย์จาก Cloudflare เพื่อวิเคราะห์เพลงและวางเรื่อง Kling สร้างคลิปจากภาพที่ตรวจผ่านทีละช็อต 5/10 วินาที
คำสั่งล็อกต้นแบบและการตรวจช็อตยังใช้ตามเดิม หน้า Login และการเปลี่ยนสีไม่มีการแก้ไฟล์ภาพต้นแบบ
โควตา Google 429/503 และเครดิต Kling ยังขึ้นกับบัญชีบริการ การปรับหน้าเว็บไม่แก้โควตาหรือรับประกันผลคลิป
ยังไม่มีการสร้างภาพนิ่งอัตโนมัติ สร้างทุกช็อตพร้อมกัน เสียงพูดอัตโนมัติ หรือดาวน์โหลดคลิปเข้าฐานข้อมูลอัตโนมัติ

## Source และการตรวจ

โฟลเดอร์ source เป็น React/Vite project รัน npm install, npm run typecheck, npm test, npm run build
เว็บพร้อมใช้ได้ใน source/dist ส่วน Worker เดิม build ด้วย npm run build:worker ได้ใน source/worker-dist
ห้ามอัปโหลด node_modules, ไฟล์ Secrets หรือ .env ไป GitHub
ตรวจ TypeScript, build และทดสอบจำลอง 52 ข้อผ่าน ยังไม่ได้ตรวจหน้าจอจริงในเบราว์เซอร์หรือเรียก AI จริง
ยังไม่ได้เผยแพร่แทนคุณ เนื่องจากการเชื่อมต่อ GitHub ที่มีอยู่ไม่ได้รับสิทธิ์เขียน repository
