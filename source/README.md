# StoryCraft Studio 1.4.0 — ชุดอัปโหลด GitHub Pages

เว็บหลัก: https://thanawid.github.io/storycraft-studio/

อัปเดตนี้เพิ่มตัวเชื่อม Kling 2.6 สำหรับสร้างวิดีโอจากภาพทีละช็อต พร้อมเลขงานสำหรับตรวจสถานะ และระบบรหัสเจ้าของฝั่ง Cloudflare
คงโทนส้ม เทา เขียวพาสเทล ฟอนต์ที่ขยายแล้ว และเอฟเฟกต์เปิดปิดได้

## เริ่มตรงนี้

1. สำรองโปรเจกต์จากเว็บเดิมก่อนอัปเดต
2. แตก ZIP แล้วอัปโหลด index.html, assets และ storycraft-icon.svg ทับไฟล์ที่ราก repository thanawid/storycraft-studio
3. Pages ใช้ main → / (root) ตามเดิม รอเผยแพร่ แล้วรีเฟรชให้เห็นเวอร์ชัน 1.4.0
4. เปิด backend/SETUP-TH.md ทำตามขั้นตอนสร้าง Cloudflare Worker และตั้ง Secrets
5. ในเว็บเปิด “การเชื่อมต่อ AI” เชื่อมส่วน Kling ด้วย Worker URL และรหัสเจ้าของ จากนั้นลองหนึ่งช็อต

**ยังไม่ได้เผยแพร่หลังบ้านหรือทดสอบกับคีย์ Kling จริง** การ build และทดสอบจำลองผ่าน 29 ข้อ ไม่ใช้ units
ไม่เคยใส่คีย์จริงใน ZIP อย่าอัปโหลดคีย์หรือรหัสลง GitHub

## ไฟล์ในชุด

- index.html, assets, storycraft-icon.svg: เว็บที่ build แล้ว อัปโหลดได้เลย
- backend/kling-worker.js: โค้ดหลังบ้านสำหรับวางใน Cloudflare Worker
- backend/SETUP-TH.md: คู่มือทีละขั้น
- source: React/Vite source สำหรับปรับต่อ พร้อม backend และ tests

## ขอบเขต Kling รุ่นแรก

สร้างจาก JPG/PNG ที่ตรวจผ่าน ไม่เกิน 4 MB, 720p, 5 หรือ 10 วินาที, ปิดเสียง
ใช้เพลงเดิมในการประกอบ MV ภายหลัง ส่วนเสียงพูดสำหรับหนัง/ละคร/นิทานยังต้องเตรียมแยก
ตัวละครหนึ่งคนต้องใช้ภาพต้นแบบเดิมเป็น first frame; ยังไม่รองรับชุดหลายภาพอ้างอิงหรือสร้างภาพนิ่งด้วย Kling
คำสั่งล็อกใบหน้าไม่รับประกันผล ต้องตรวจคลิปจริงทุกช็อต ไม่อนุมัติคลิปให้อัตโนมัติ
คลิปเสร็จแล้วเปิดดาวน์โหลดและแนบกลับในช็อต ยังไม่ดาวน์โหลดเข้าโปรเจกต์อัตโนมัติ
บันทึกเลขงานก่อนส่ง ไม่ส่งงานสร้างซ้ำอัตโนมัติ ปิดแท็บไม่ยกเลิกงานที่ส่งแล้ว

## Gemini และข้อมูลเดิม

Gemini ยังใช้คีย์ของคุณในหน่วยความจำแท็บ ปิดหรือรีเฟรชต้องกรอกใหม่ ใช้สำหรับวิเคราะห์เพลงและสร้างสตอรีบอร์ด
Kling เป็นคนละบริการ การต่อ Kling ไม่แก้ Gemini 503 หรือโควตา Google
โปรเจกต์เก็บในเบราว์เซอร์ของคุณ และสำรอง JSON ได้ รวมเลขติดตาม Kling และภาพเริ่มเดิม แต่ไม่รวมคีย์/รหัส/เซสชัน
เว็บ GitHub Pages เปิดสาธารณะ หลังบ้าน Kling ต้องใช้รหัสเจ้าของ ทุกคนที่ไม่มีรหัสจึงไม่สามารถใช้ units ของคุณผ่านหลังบ้านนี้
อย่าแชร์รหัสเจ้าของ เปลี่ยน STUDIO_PASSWORD ใน Cloudflare หากต้องการยกเลิกเซสชันเดิมทั้งหมด

## แก้ไขและ build

เข้า source แล้วรัน npm install, npm run typecheck, npm test, npm run build
อัปโหลดเนื้อหาภายใน source/dist ทับไฟล์เว็บที่ราก repository
ถ้าแก้ backend ให้ Deploy Worker ใหม่แยกจากเว็บ
ไม่ต้องอัปโหลด node_modules, dist ซ้ำใน source หรือไฟล์ Secrets

การทดสอบรอบนี้ครอบคลุมการยืนยันเจ้าของ, ป้องกันคำขอที่ไม่มีรหัส, ไม่ส่ง POST ซ้ำเมื่อเน็ตหลุด, การค้นงานด้วยเลขเดิม และการรักษาภาพต้นฉบับ
ยังไม่ได้ตรวจหน้าจอจริงในเบราว์เซอร์หรือสร้างคลิปด้วยบัญชีคุณ
