# StoryCraft Studio 1.5.0

เว็บหลัก https://thanawid.github.io/storycraft-studio/

รุ่นนี้ไม่ต้องกรอก API key ในหน้าเว็บอีก: Gemini และ Kling ใช้คีย์จาก Cloudflare Secrets
เข้าสู่ระบบเจ้าของครั้งเดียว เลือกจำเครื่องส่วนตัว 7 วัน แล้วเปิดเว็บหรือรีเฟรชกลับมาทำต่อได้
โทนส้ม เทา เขียวพาสเทล ฟอนต์อ่านง่าย เอฟเฟกต์เปิดปิดได้ และหน้าตั้งค่าอยู่กลางจอ
ช็อตใหม่เริ่มที่ 5 วินาที ปุ่มเปิดช็อตระบุชัดว่าใช้สร้างคลิปได้

## อัปเดตครั้งเดียวตามลำดับ

1. สำรอง JSON โปรเจกต์จากเว็บเดิม
2. วาง backend/kling-worker.js ที่ราก ZIP ทับโค้ด Cloudflare Worker เดิมแล้ว Deploy
3. เพิ่ม GEMINI_API_KEY เป็น Secret ใน Worker คง KLING_API_KEY และ STUDIO_PASSWORD เดิมไว้
4. ตั้ง ALLOWED_ORIGIN เป็น https://thanawid.github.io และ GEMINI_MODEL เป็นรุ่นที่บัญชีมีสิทธิ์/โควตา
5. อัปโหลด index.html, assets และ storycraft-icon.svg ที่ราก ZIP ทับไฟล์เว็บ GitHub
6. เปิดเว็บ → การเชื่อมต่อ AI → ใส่รหัสเจ้าของเดิม → เลือกจำเครื่อง 7 วัน → เข้าสู่ระบบ

คู่มือเต็ม: backend/SETUP-TH.md
อย่าวาง source/backend/kling-worker.js ใน Cloudflare Dashboard โดยตรง เพราะ source ยังมี import ต้อง build ก่อน
ไฟล์ backend/kling-worker.js ที่ราก ZIP เป็นไฟล์เดียวที่ bundle พร้อมใช้แล้ว

## ขอบเขตที่ใช้ได้

- วิเคราะห์เสียง/เนื้อเพลง วางเรื่อง MV หนัง ละคร นิทานผ่าน Gemini พร้อมต้นแบบเดิมที่ตรวจ hash
- สร้างคลิปจากภาพที่ตรวจผ่านทีละช็อตผ่าน Kling 2.6, 720p, ปิดเสียง, 5/10 วินาที
- ล็อกต้นแบบและสไตล์ ไม่ซ่อมใบหน้า ไม่ใช้ช็อตที่สร้างเป็นต้นแบบใหม่ ผลจริงต้องตรวจทุกช็อต
- เก็บเลขงานก่อนสร้าง ติดตามงานเดิม ไม่มีการส่งสร้างซ้ำอัตโนมัติ
- สำรอง/นำเข้าโปรเจกต์ และประกอบคลิปที่อนุมัติกับเพลงต้นฉบับในเบราว์เซอร์

ยังไม่มีการสร้างภาพนิ่งอัตโนมัติ สร้างทุกช็อตพร้อมกัน เสียงพูดอัตโนมัติ หรือดาวน์โหลดคลิปเข้าฐานข้อมูลอัตโนมัติ
Kling โหมดตัวละครรองรับต้นแบบหนึ่งคนเป็นภาพเริ่ม ยังไม่ส่งชุดหลายภาพอ้างอิง
Gemini 429/503 หรือเครดิต Kling ไม่พอยังต้องแก้ที่บัญชีบริการ การจำคีย์ไม่เพิ่มโควตา

## ความเป็นส่วนตัว

API key อยู่ใน Cloudflare Secrets เท่านั้น ไม่อยู่ใน frontend หรือ ZIP ไม่ส่งกลับเบราว์เซอร์
รหัสเจ้าของไม่บันทึกลง localStorage การจำเครื่องเก็บเฉพาะเซสชันที่หมดอายุภายใน 7 วัน ซึ่งให้สิทธิ์ใช้เครดิต จึงใช้เฉพาะเครื่องส่วนตัว
ออกจากระบบเพื่อลืมเครื่อง หรือเปลี่ยน STUDIO_PASSWORD ใน Cloudflare เพื่อยกเลิกเซสชันทั้งหมด
โปรเจกต์อยู่ใน IndexedDB ของเครื่องคุณ สำรอง JSON เมื่อต้องการย้ายเครื่อง ไม่มีคีย์ รหัส หรือเซสชันในไฟล์สำรอง

## Source

โฟลเดอร์ source เป็น React/Vite project:
```
npm install
npm run typecheck
npm test
npm run build
npm run build:worker
```
อัปโหลดเนื้อหา source/dist ไป GitHub Pages และ source/worker-dist/kling-worker.js ไป Cloudflare
รุ่นนี้ตรวจ TypeScript, build เว็บ/Worker และทดสอบจำลอง ไม่ได้เรียก AI จริงหรือใช้ units
ยังไม่ได้ตรวจหน้าจอจริงในเบราว์เซอร์ และยังไม่ได้เผยแพร่แทนผู้ใช้
